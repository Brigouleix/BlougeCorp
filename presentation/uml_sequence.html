UML 2.5 · Flux Connexion, Création de destination, Envoi d'invitation et Road Trip

1 · Flux de Connexion (Login)

L'utilisateur saisit ses identifiants → le frontend envoie une requête POST → le backend valide, génère un JWT et le renvoie → le frontend stocke le token dans localStorage.

sequenceDiagram autonumber actor U as 👤 Utilisateur participant F as ⚛️ Frontend
(React) participant A as 🔒 AuthController
(PHP) participant DB as 🗄️ Database
(MySQL) participant LS as 💾 localStorage U->>F: Saisit email + mot de passe F->>F: Validation basique (champs non vides) F->>A: POST /api/auth/login
{ email, password } A->>DB: SELECT * FROM users
WHERE email = ? DB-->>A: Row utilisateur (hash, isAdmin…) alt Email inexistant A-->>F: 401 { error: "Identifiants invalides" } F-->>U: ❌ Affiche message d'erreur else Mot de passe incorrect A->>A: password_verify() → false A-->>F: 401 { error: "Identifiants invalides" } F-->>U: ❌ Affiche message d'erreur else Connexion réussie A->>A: password_verify() → true A->>A: JWT::encode({ id, username,
email, isAdmin }) A-->>F: 200 { token, user } F->>LS: setItem('token', token)
setItem('user', JSON) F-->>U: ✅ Redirige vers /my-groups end

2 · Flux d'Inscription (Register)

L'utilisateur crée un compte avec username, email et mot de passe. Le backend vérifie l'unicité, hash le mot de passe avec bcrypt et insère la ligne.

sequenceDiagram autonumber actor U as 👤 Utilisateur participant F as ⚛️ Frontend participant A as 🔒 AuthController participant DB as 🗄️ Database U->>F: Remplit le formulaire
(username, email, password) F->>A: POST /api/auth/register
{ username, email, password } A->>DB: SELECT COUNT(*) FROM users
WHERE email = ? OR username = ? DB-->>A: count alt Email ou username déjà pris A-->>F: 409 { error: "Email ou pseudo déjà utilisé" } F-->>U: ❌ Message d'erreur else Données valides A->>A: password_hash(password, BCRYPT) A->>DB: INSERT INTO users
(username, email, password) DB-->>A: lastInsertId A->>A: JWT::encode(payload) A-->>F: 201 { token, user } F-->>U: ✅ Redirige vers /my-groups end

Le membre d'un groupe soumet un formulaire de destination. Le frontend géolocalise l'adresse via Nominatim, puis envoie la destination complète au backend.

une requête de géocodage F->>N: GET /search?q=adresse&format=json N-->>F: [{ lat, lon, display_name }] F->>F: Affiche suggestion sur carte Leaflet U->>F: Confirme & soumet F->>D: POST /api/destinations
Authorization: Bearer
{ groupId, name, image, prices, dates,
proposedBy, members, location } D->>D: JWT::getUserFromRequest() D->>DB: INSERT INTO destinations (…) DB-->>D: lastInsertId alt Succès D-->>F: 201 { destination } F-->>U: ✅ Nouvelle carte destination ajoutée else Erreur (groupId manquant, token invalide…) D-->>F: 4xx { error: "…" } F-->>U: ❌ Message d'erreur end

4 · Envoi d'une Invitation à un Groupe

Le créateur du groupe invite des utilisateurs par email. Le backend insère l'invitation, envoie un mail via PHPMailer/Brevo avec un lien d'accès.

sequenceDiagram autonumber actor C as 👑 Créateur participant F as ⚛️ Frontend participant G as 👥 GroupController participant DB as 🗄️ Database participant M as 📧 PHPMailer
(Brevo SMTP) actor I as 📥 Invité C->>F: Saisit email(s) à inviter F->>G: POST /api/groups/{id}/invite
Authorization: Bearer
{ emails: ["a@b.com", …] } G->>G: JWT::getUserFromRequest() G->>DB: SELECT * FROM groups WHERE id = ? DB-->>G: groupe + creatorId loop Pour chaque email G->>DB: INSERT INTO invitations
(groupId, email, status='pending') DB-->>G: OK G->>M: sendInviteEmail(email, groupName,
APP_URL + /register ou /login) M-->>I: 📨 Email "Vous êtes invité dans "
Boutons : S'inscrire / Se connecter end G-->>F: 200 { sent: n } F-->>C: ✅ "n invitation(s) envoyée(s)" Note over I,M: L'invité clique sur le lien dans l'email I->>F: Ouvre APP_URL/register (ou /login) F-->>I: Formulaire d'inscription/connexion

5 · Réinitialisation du Mot de Passe

L'utilisateur demande un lien de réinitialisation. Le backend génère un token à durée de vie limitée, l'envoie par email, puis valide le token lors du changement.

sequenceDiagram autonumber actor U as 👤 Utilisateur participant F as ⚛️ Frontend participant A as 🔒 AuthController participant DB as 🗄️ Database participant M as 📧 PHPMailer U->>F: Clique "Mot de passe oublié"
Saisit son email F->>A: POST /api/auth/forgot-password
{ email } A->>DB: SELECT * FROM users WHERE email = ? DB-->>A: user (ou vide) alt Email introuvable A-->>F: 200 { message: "Si cet email existe…" } Note over A: Réponse identique pour éviter
l'énumération d'emails else Email trouvé A->>A: token = bin2hex(random_bytes(32))
expiry = NOW() + 1h A->>DB: UPDATE users SET reset_token = token,
reset_expiry = expiry WHERE id = ? A->>M: sendResetEmail(email,
APP_URL + /reset-password?token=…) M-->>U: 📨 Email avec lien de réinitialisation A-->>F: 200 { message: "Email envoyé" } F-->>U: ✅ "Consultez votre boîte mail" end U->>F: Clique lien dans l'email
Saisit nouveau mot de passe F->>A: POST /api/auth/reset-password
{ token, password } A->>DB: SELECT * FROM users
WHERE reset_token = ? AND reset_expiry > NOW() DB-->>A: user (ou vide) alt Token invalide ou expiré A-->>F: 400 { error: "Token invalide ou expiré" } F-->>U: ❌ Message d'erreur else Token valide A->>A: password_hash(password, BCRYPT) A->>DB: UPDATE users SET password = hash,
reset_token = NULL, reset_expiry = NULL A-->>F: 200 { message: "Mot de passe modifié" } F-->>U: ✅ Redirige vers /login end

6 · Création d'un Road Trip

Le membre sélectionne plusieurs destinations du groupe, les ordonne, puis sauvegarde le road trip. Le backend calcule le budget total et génère un export PDF.

sequenceDiagram autonumber actor U as 👤 Membre participant F as ⚛️ Frontend participant R as 🗺️ RoadTripController participant D as 📍 DestinationController participant DB as 🗄️ Database U->>F: Ouvre page Road Trip du groupe F->>D: GET /api/destinations?groupId=X D-->>F: [ destinations du groupe ] F-->>U: Liste de destinations à sélectionner U->>F: Sélectionne N destinations
+ ordonne par drag & drop F->>R: POST /api/roadtrips
Authorization: Bearer
{ groupId, destinationIds: [3,1,5] } R->>R: JWT::getUserFromRequest() R->>DB: INSERT INTO road_trips
(groupId, destinationIds JSON, createdBy) DB-->>R: lastInsertId R->>DB: SELECT * FROM destinations
WHERE id IN (3,1,5) DB-->>R: destinations[] R->>R: Calcule totalBudget
= Σ(priceHouse + priceTravel) R-->>F: 201 { roadtrip, totalBudget, destinations } F-->>U: ✅ Road trip créé
Affiche itinéraire + budget total opt Export PDF U->>F: Clique "Exporter PDF" F->>F: Génère PDF côté client
(carte + destinations + budget) F-->>U: 📄 Téléchargement PDF end
