🔐 Sécurité

JWT HS256

Tokens signés côté serveur avec clé secrète. Payload : id, username, email, isAdmin. Expiration configurable.

BCrypt Password Hashing

password_hash() avec PASSWORD_BCRYPT. Vérification via password_verify(). Aucun mot de passe en clair.

Prepared Statements PDO

Toutes les requêtes SQL utilisent des paramètres bindés. Protection totale contre les injections SQL.

CORS configuré

Origines autorisées listées explicitement. Headers Authorization, Content-Type acceptés. Préflight OPTIONS géré.

Vérification des droits

Chaque action sensible vérifie l'appartenance au groupe ET le rôle (créateur, proposeur, admin) côté serveur.

Reset Token à usage unique

Token cryptographiquement sûr (32 octets), expirant après 1h, invalidé après utilisation.

Admin server-side

Le rôle admin est vérifié en comparant l'email du JWT à l'email admin défini côté serveur uniquement.

Images en Base64

Les images sont stockées en base64 en BDD (TEXT). Pas de stockage de fichiers physiques, pas de path traversal.
